# StarkFFA packs
- `starkFFA-Pack.zip` – old v1 pack (custom item models, scoreboard art). Not used on the current server.
- `v2/starkffa-pack-v2.zip` – current server pack: pixel icons (font `starkffa:icons`) and UI panel. Source in `v2/src`, rebuild with `v2/build_pack.py`.
- Download URL for server.properties: `https://raw.githubusercontent.com/ppie-png/starkffa-pack/main/v2/starkffa-pack-v2.zip`
- SHA-1: see `v2/sha1.txt` (first 40 characters).
