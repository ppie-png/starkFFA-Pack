# StarkFFA — Resource Pack

Resource pack for the StarkFFA server (Paper 26.3, pack format 97).
Everything is generated by `tools/build_pack.py` — edit the script, never the PNGs.

```
python3 tools/build_pack.py   # -> pack/ + dist/StarkFFA-pack.zip + dist/sha1.txt
```

The server loads `dist/StarkFFA-pack.zip` straight from this repo
(`server.properties` → `resource-pack` = raw URL, `resource-pack-sha1` = `dist/sha1.txt`).
After every rebuild: commit + push, then update the sha1 on the server.

| What | Where | Docs |
|---|---|---|
| Tooltip styles per weapon theme (`starkffa:wind`, …) | `assets/starkffa/textures/gui/sprites/tooltip/` | [docs/TOOLTIPS.md](docs/TOOLTIPS.md) |
| HUD font `starkffa:hud` (cooldown bar, ability icons, spaces) | `assets/starkffa/font/hud.json` | [docs/HUD.md](docs/HUD.md) |
